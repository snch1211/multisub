**描述**：

MultiSub 是 Safari 延伸功能。在 Mac 上用 Safari 看 Netflix 時，畫面會同時顯示兩種語言的字幕，看劇順便學語言。

預設是 Netflix 雙語字幕，打開 Netflix 播放就有。想換模式，點 Safari 工具列的 MultiSub 按鈕切換，選過就會記住：

• Netflix 雙語字幕
直接疊上 Netflix 官方提供的第二語言字幕。不用 AI、不用設定，裝好就能用。

• AI 翻譯雙語字幕
Netflix 沒提供你要的語言時，改由 AI 翻譯原文字幕，支援 12 種語言。可以選完全在 Mac 上執行的本機模型（免費、離線），也可以填入自己的 Anthropic、OpenAI、OpenRouter 或 Google Gemini API Key，不用下載模型、速度更快。

• 生字標註
畫面上只留原文字幕，依你設定的程度（初級到高級），只在比較難的單字和片語後面加上簡短的意思。意思貼合這一句的劇情，Netflix 有官方翻譯時還會對照官方用詞，不會硬套字典讓你卡住。

其他功能：
• 生詞本：在選單按「整理本集單字」，App 會在背景讀整集的英文字幕，挑出值得學的單字和片語，依 CEFR 分級整理，附上解釋、翻譯和例句。可以邊整理邊看，之後隨時回來複習
• 字幕樣式：字級、位置、顏色、外框、字型都能調，也能直接在影片上拖曳位置
• 從目前播放的位置開始處理，跳轉後會優先處理你正在看的段落
• 翻譯結果會保存，重看同一集不必重新處理

## English

**Name**: MultiSub: Bilingual Subtitles

**Subtitle**: Learn languages from shows

**Promotional text**:
Watch Netflix in Safari with subtitles in two languages. New Word Notes mode explains only the words you might not know, so you keep up and learn as you go.

**Keywords**:
dual,subtitle,translate,language,learning,vocabulary,english,chinese,japanese,korean,safari,cefr,ai

**Description**:

MultiSub is a Safari extension that shows subtitles in two languages while you watch Netflix in Safari on your Mac, so every episode doubles as language practice.

Netflix bilingual subtitles is on by default, so there is nothing to set up. To switch modes, click the MultiSub button in the Safari toolbar; your choice is remembered.

• Netflix bilingual subtitles
Shows Netflix's own subtitle track in your second language under the original. No AI, no setup.

• AI translation
When Netflix doesn't offer your language, MultiSub translates the original subtitles into one of 12 languages. Use the free on-device model that runs entirely on your Mac, or bring your own Anthropic, OpenAI, OpenRouter or Google Gemini API key for faster results with nothing to download.

• Word Notes
Keeps only the original subtitle on screen and adds a short meaning after the words and phrases that are likely new at your level (beginner to advanced). Meanings fit the scene, and when Netflix has an official translation in your language they follow its wording, so you get the sense used there rather than a dictionary guess.

Also included:
• Vocabulary list: click "Organize this episode's words" and the app picks out the words and phrases worth learning from the episode's English subtitles and sorts them by CEFR level in the background, with definitions, translations and example sentences
• Subtitle styling: size, position, colors, outline and font, or drag the subtitle into place on the video
• Starts from where you are watching and jumps ahead with you when you skip
• Results are saved, so rewatching an episode is instant

Privacy:
No account and no analytics. If you only use Netflix bilingual subtitles, subtitles go nowhere. With the on-device model as the AI engine, translation, Word Notes and the vocabulary list all run on your Mac. With a cloud AI engine, AI translation, Word Notes and the vocabulary list send subtitles directly from your Mac to the provider you chose, after you first agree to it.

Requirements:
• A Mac with Apple silicon running macOS 15 or later
• Safari and a Netflix subscription
• For the optional on-device model: 16 GB of memory recommended and 3–5 GB of disk space

MultiSub is an unofficial open-source community project. It is not affiliated with, endorsed or sponsored by Netflix. Netflix is a trademark of Netflix, Inc.

## Notes for App Review (English)

MultiSub is a Safari Web Extension contained in this app. It runs only on netflix.com, inside the user's own signed-in Netflix session. It reads the subtitle track list from the playback manifest Netflix's player requests (also asking Netflix for its WebVTT subtitle format), fetches the needed subtitle tracks from Netflix, and draws them over the player. It never touches video or DRM and has no export feature. Processed results are cached in the extension's local storage. The only subtitle text written to disk by the app is the current episode's English lines, staged when the user clicks "整理本集單字" (Organize this episode's words) and deleted once the word list is built (a failed attempt keeps them for retry until the user removes it, or for at most 24 hours).

How to test:
1. Open MultiSub. There are no accounts or sign-in. The "開始使用" (Get started) page shows whether the Safari extension is on and opens Safari's extension settings. Enable "MultiSub" and choose "Always Allow" for netflix.com.
2. In Safari, sign in to netflix.com with your own Netflix subscription (MultiSub does not provide one) and play a title with English audio. Netflix bilingual subtitles is the default mode and needs no setup.
3. The second language follows the Mac's system language. On an English-language Mac, click the MultiSub toolbar button and set "第二語言" (Second language) to 繁體中文 or Español. The three tabs at the top of the popup switch modes: "Netflix 字幕" (Netflix subtitles), "AI 翻譯" (AI translation) and "生字標註" (Word Notes).
4. While English subtitles play, click "整理本集單字" (Organize this episode's words) in the popup. Safari opens the MultiSub app, which builds the list under "生詞本" (Vocabulary) with the AI engine set in "一般設定" (General settings). If its window is closed, the app keeps running until the list is done, then quits.

Without Netflix, every screen of the app can still be reviewed. The on-device model download contains only model weights, configuration files and a chat template (.safetensors, .json, .jinja), no executable code.

The three modes:
- Netflix bilingual subtitles: overlays Netflix's own second-language subtitle track. Needs no AI and no API key.
- AI translation: translates the original subtitles with the free on-device model (downloaded only after the user taps Download; the size is shown first) or, optionally, the user's own API key.
- Word Notes: shows the original subtitle with short meanings after difficult words, using the same engine choice.

No feature requires an API key or any purchase: Netflix mode needs nothing, and both AI modes and the vocabulary list work with the free on-device model. An API key is an optional alternative engine supplied by the user for their own account; MultiSub does not sell, provide or unlock anything with it. Keys are entered only in the app and stored in the macOS Keychain.

External services contacted: Hugging Face (model sizes when the user expands "可下載的模型" (Downloadable models) or views an on-device model that isn't downloaded yet; the model download only when the user taps Download; a downloaded model loads from disk without contacting it), and only if the user enters their own key: api.anthropic.com, api.openai.com, openrouter.ai, generativelanguage.googleapis.com, or a custom OpenAI-compatible URL the user types. With a cloud provider, AI translation and Word Notes send the episode's subtitle lines in batches, and "整理本集單字" sends that episode's English subtitle lines in segments to build the word list. "儲存並測試" (Save and test) first sends one fixed English test sentence (not subtitle text) with the typed settings; nothing is saved unless it succeeds. The first time a provider is saved, the app also asks the user to agree, naming the provider (or the custom URL) that will receive subtitle text; saving a different custom URL asks again. No subtitle text is sent to a provider the user hasn't agreed to.
